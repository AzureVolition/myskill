# Project Instructions

This repository stores reusable Codex Skills.

- Keep each skill in its own directory under `skills/<skill-name>/`.
- Preserve each skill's `SKILL.md`, scripts, assets, tests, and license.
- Do not commit generated books, temporary conversion directories, Python bytecode, or virtual environments.
- After changing a skill, run its available tests and validate its `SKILL.md` before committing.
- Keep project-level documentation focused on installation and discovery; detailed workflow instructions belong in the individual skill.
